# 写今日工作日志

只写自己的提交，别人一条不进。不落盘，正文整块发在对话里。

## 取我的今日提交

只在当前仓库取；cwd 不是仓库时问一句是哪个项目，别扫全工作区。

```bash
date +%F; git rev-parse --show-toplevel
git config user.name; git config user.email      # 命中其一就算自己
git log --since="<日期> 00:00" --until="<日期> 23:59:59" --no-merges \
  --max-count=200 --author="<name>" --author="<email>" \
  --date=format:'%H:%M' --pretty='===== %h %ad %s%n%b'
```

- 没配的身份别传空 `--author`（空串匹配所有人）；今天没用过这个身份，就看当日 `%an <%ae>` 计数挑出自己，标题行写「按 <名字> 算」。
- `--max-count` 不能省：wrapper 会把列表截到 10 条。
- 无输出 = 今日没有我的提交：只给标题行与「今日没有我的提交」，不拿别人的顶上。

## 读改动

先读 `%b`，正文通常已写清为什么；正文薄才 `git show <hash>`（小的读全量，大的先 `--stat` 挑新文件、被删路径、测试改动）。按主线并成 2～5 个主题。

## 写作

正文包在 ``` 围栏里，内容纯文本：一行一个任务，缩进两格，每行 ≤20 字。

````text
```text
2026-11-10 · 13 提交
  轮次收成 Turn，修引用错位
  小程序独立模型
  超时统一翻倍

进行中：src/store/* 未提交
```
````

硬指标：每行 ≤20 字（首行与「进行中」行也算）、一行一个任务、总长 ≤12 行、工作树干净删掉「进行中」行；压不进 20 字就删次要细节，不折行不拖尾巴。

规模一条命令算，别估：

```bash
git log --since="<日期> 00:00" --until="<日期> 23:59:59" --no-merges \
  --max-count=200 --author="<身份>" --numstat --pretty=format: \
  | awk 'NF==3{f[$3]=1;a+=$1;d+=$2} END{for(x in f)n++;printf "files=%d +%d -%d\n",n,a,d}'
```

## 规矩

- 正文包在 ``` 围栏里，块外只留一句「今日 N 个提交」。
- 只有自己的提交：别人的不列、不提、不算，数字也只在自家人里统计。
- 每句对应得到某个提交（hash 不写出来）；说不准的不写，不补因果。
- 中文全角标点，代码、路径、数字半角；不写「综上所述」「本次」这类空话。
