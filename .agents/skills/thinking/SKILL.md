# Thinking Frameworks

Five mental models, one entry point. **Select exactly one method, then read only its
reference file** — do not load the others.

## Dispatch table

| Method | Use when the task is… | Reference |
|--------|----------------------|-----------|
| First Principles | breaking a problem down to verifiable fundamentals and rebuilding, bypassing inherited assumptions | `references/first-principles.md` |
| Inversion | stress-testing a plan or goal by asking what would cause failure; pre-mortem | `references/inversion.md` |
| Ladder of Inference | tracing a conclusion or judgment back to raw data to expose skipped reasoning steps | `references/ladder-of-inference.md` |
| Minto Pyramid | structuring a message, doc, or report conclusion-first (SCQA / BLUF) | `references/minto-pyramid.md` |
| Second-Order Thinking | evaluating a decision by mapping consequences beyond the immediate outcome ("and then what?") | `references/second-order-thinking.md` |

## Selection rules

- An explicit method name (or its trigger phrase) from the user wins — no second-guessing.
- Otherwise pick by the task's shape per the table above. If two genuinely apply,
  state the choice in one line and proceed with one; run a second method only if
  the user asks.
- Rough boundary between the analysis lenses: *assumptions about the problem* →
  first-principles; *risks of a plan* → inversion; *grounding of a conclusion
  already drawn* → ladder-of-inference; *future consequences of a choice not yet
  made* → second-order-thinking. Minto is for communicating results, not analyzing.
